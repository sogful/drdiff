what this is

a side-by-side of how deltarune's decompiled game code changed from patch to patch, with each update's official changelog pinned next to the actual code that moved.

how it was built

  • every patched build was pulled straight from steam's depots by manifest id (depot 1671212).
  • each build's data.win per chapter was decompiled to gml with a fork of undertalemodtool (underanalyzer).
  • builds were identified by their in-game version string (global.versionno / global.version) rather than trusting file order.
  • consecutive builds were diffed file-by-file, line-by-line.
  • changelog notes were pulled from the official @UNDERTALE account and OCR'd from the patch-note images.

the two eras

the tracked builds split into two shapes. the release era (chapters 1-4) and the chapter 5 era (chapters 1-5). each chapter ships its own data.win, so diffs are clean within an era.

exclusions

when a whole chapter is introduced in a single update (chapter 5 landing on top of the release era), thousands of brand-new code entries appear at once. that bulk addition is collapsed to a count rather than exploded line-by-line, so the boundary step stays about what actually changed in the existing chapters. these steps are marked era boundary.

reading a diff

  • pick a version step on the left. each shows the launcher plus every chapter.
  • green ADD / red DEL / blue MOD tag each changed code entry.
  • click a modified entry to expand its line diff.
  • the official changelog for that version sits at the top, image and all.
