# DELTARUNE Chapter 5 v0.0.250 Patch

Today we released an update for PC/Mac and PlayStation to fix a few issues with the game.
You can confirm the chapter version number on the bottom right of the file select screen.

# Chapter 5 Version 0.0.250

### GAMEPLAY ADDITIONS
- A Golden Tenna Statue will now appear in Castle Town in Chapter 5 if you got it from the Ball Machine in Chapter 3.
- The ability to permanently re-enable Voice Clips has been shoddily added if you lose to the Chapter Boss and have them disabled.

### GAMEPLAY ISSUES
- In Chapter 4, defeating a Titan Spawn with violence no longer erroneously counts as "Lost". We also fixed an issue in Chapter 5 where Jackenstein would not appear in your town because of this.
- Susie now has additional magic points in Chapter 5 if you defeated the Shadow Crystal boss of Chapter 4.
- Fixed some issues where the number on the TP display was occasionally inaccurate.
- You can no longer incorrectly leave a certain scene by frame-perfectly opening the menu in the Light World.
- Fixed an issue where on gamepads, ZL / L2 would count only as a single frame press of confirm in Chapter 5 only.
- Fixed an issue involving bugged blank item slots which had been carried over from Chapter 4 save files before it was fixed in that chapter.
- Fixed an issue where you can clip through the floor after fighting three scarecrows by immediately opening the ACT menu, and other bugs involving the ACT menu.
- You can no longer crash the game by hitting an enemy and a Mysterious Statue at the same time. (Unless you can)
- You can no longer walk around during combat by interacting with Final Starwalker on the same frame you engage a battle. (And other similar issues)
- Fixed various scenarios where you can move around with the menu open.
- Fixed certain bullet patterns not giving TP when grazed.
- Kris will no longer stay sideways if you enter into the final cutscene of Chapter 5 sideways.
- Fixed MANY other minor issues, visual or otherwise.

### NEXT TIME
In the next patch, we will add an option to nerf the bombs of the Shadow Crystal boss after losing to them once. Additionally, we plan to fix a small number of bugs in previous chapters which had gone unaddressed up until this point.
There is no plan for another extensive Chapter 5 patch after the next one. Instead, we will resume fully concentrating our development resources on Chapter 6 and 7.
