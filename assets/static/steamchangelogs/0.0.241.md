# DELTARUNE Chapter 5 Hotfix Patch (Chapter 5 Version 0.0.241)

We have released a quick update to fix a few issues with the game.
You can confirm the chapter version number on the bottom right of the file select screen.
### DELTARUNE Chapter 5 Version 0.0.241 for PC/Mac

- Fixed an issue where, towards the end of a boss, when the music becomes slow, flirting would softlock the game.
- Fixed a softlock when pressing Z&X simultaneously when interacting with a disappearing fox. Also fixed another bug in the same scenario.
- Fixed a crash when knives spawn from an aqua-colored enemy, and after said enemy is defeated.
- Fixed a crash when collecting candy from a green-colored enemy.
- Fixed a situation where Kris could be gigantic and the game was unplayable if you had modified your save file in a previous Chapter.
- The last boss of the chapter becomes gradually easier after losing an excessive amount of times in one play session.

We will continue to address bugs as quickly as we can.
Thank you for you playing, and for your patience with these issues!
