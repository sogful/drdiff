# Chapter 5 Version 0.0.242 (Hotfix Patch)

Another quick fix for some bugs some players were encountering.

- Fixed a crash towards the end of the game in an area with a yellow guy in the background.
- Fixed a crash involving a small glove.
- Fixed a crash when encountering a leaf enemy while leaving a room.
- Opening a pink door at a precise location no longer makes the screen go black.
- Magical glass was placed over a wall you're not supposed to go over.
- Using Rudebuster in the final phase of a pink enemy no longer crashes the game.
- Fixed a crash if you put Ralsei in your party before sleeping in bed to skip the intro.
- Fixed a crash when Trashy Trio are defeated.
- Fixed a memory leak which could crash the game if certain actions were repeated an excessive number of times.

We are aware of other issues and are working to fix them! Thank you so much to everyone that has reported anything so far.
