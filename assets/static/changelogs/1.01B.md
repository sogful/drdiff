# DELTARUNE Hotfix Patch

We are releasing a hotfix to remedy some issues occurring in the game on PC&Mac. You can confirm the version number on the bottom right of the file select screen.

### Ch3 v.0.0.088
- Fixed a softlock where you can get teleported to the Green Room during the battle with one of the final bosses, and be permanently unable to progress if you save. (This fix prevents the issue from happening again, but unfortunately if you had this bug occur, your save file will still be broken.)
- Fixed a softlock where the raft could get stuck in a wall.
- Fixed a crash if you lose to the first miniboss with zero points.
- Fixed a depth issue with a black tile.
- Some players’ computers are not compatible with the method of video display in Chapter 3. if you reach a cinematic which crashes or freezes your game, returning to that scene once more will give you the option to skip it.
- Fixed a bug when receiving a prize for attaining the highest rank.
- After defeating a certain a boss, if your inventory is too full to receive the armor in the chest, a treasure chest will be placed into the Green Room.

### Ch4 v.0.0.087
- Fixed an issue where the game would crash when loading a file from Chapter 3.
- Fixed a crash with a scene that could happen at the end of an area.
- Fixed an issue of trapped in the closet.

> We are aware of many other remaining issues, so we will be issuing one last hotfix patch soon! After the next hotfix is on PC, we will generate a patch for consoles.
