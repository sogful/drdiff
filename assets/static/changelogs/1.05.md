# DELTARUNE STEAM BETA BRANCH - PATCH 1.05

This time, adjustments to gameplay are rather insignificant, but we made two global changes 1.05 to a beta branch on Steam before giving it a full release. If anybody was just going to play the game for fun, it would be appreciated if you could play Multiple Chapters

### Version Numbers
| | PC/Mac | Switch/Switch 2 | PS4/PS5 |
|---|---|---|---|
| Chapter 1 | 1.41 |
| Chapter 2 | 1.47 |
| Chapter 3 | v.0.0.099 |
| Chapter 4 | v.0.0.100 |

- We had to upgrade our version of GameMaker to fix a PlayStation-specific bug. The game will now run at 30 FPS (as intended) instead of 31-32 FPS on PS4 and PSS. Ideally there should be no other changes as a consequence of this upgrade, but we just want to make sure.
- Cutscenes are now loaded more efficiently. This will reduce hiccups on PlayStation, as well as on weaker PCs. (For most players, there should be NO CHANGE.)
- Fixed a combination of inputs that would crash the game in several shops.
- A couple other minor fixes.

### Chapter 4
- When facing bosses that swing down with a hammer, the hitbox of the attack now better matches the area shown by the preceding flash.
- Fixed a bug which would generate empty items in your Dark World inventory if you used the Bandage in the Light World.
- We are not working on any other patches at this time. Instead, we want to concentrate all of our resources on completing Chapter 5.
- We would like to give a progress update on the status of Chapter 5 next month (September 2025)
- via a newsletter.
