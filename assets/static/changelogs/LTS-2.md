<div class="cltri">

    <p>The menu should be more compatible with different controllers' analog sticks. (Let us know if it works!!!)</p>

    <p>Selecting a chapter and holding down the confirm button no longer skips the Legend.</p>

  <div class="cltribottom">

      <p>The time on the file select screen should display in hours:minutes:seconds.</p>

    <div>
