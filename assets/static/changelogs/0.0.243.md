# DELTARUNE PC/Mac Hotfix Update

Today we released an update for PC/Mac to fix a few issues with the game. You can confirm the chapter version number on the bottom right of the file select screen.

- Fixed a bug where losing to the last boss of the chapter, leaving the area without saving, then getting a game over elsewhere would result in the file failed to load (dogcheck) screen.
- Fixed a crash in a room where you can spend Pink Coins.
- Attempted a fix for a crash when lyrics are displayed onscreen.
- Fixed a softlock when entering a room where you are blown upwards by wind, without dashing.
- Fixed a softlock where a large yellow gun could move offscreen forever.
- Fixed a softlock where a giant pair of glasses could become invincible forever.
- Fixed a softlock in a certain Festival after talking to the guy who regrets buying round things, saving, then reloading the game, then talking again.
- Added a failsafe to the scissor cutting ACT where the ACT will end automatically if enough time passes without initially moving.
- Sprites no longer disappear when trying to put your hands in the grape I mean eyeball bowl.

> We will continue to address issues as quickly as we can. Thank you for your patience and for playing the game!
