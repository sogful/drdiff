# DELTARUNE PC/Mac Hotfix Update

Today we released an update for PC/Mac to fix a few issues with the game. You can confirm the chapter version number on the bottom right of the file select screen.

- Fixed a softlock when using a Flirt ACT against a pink-colored enemy when the music becomes slow towards the end of the battle.
- Fixed a softlock when pressing Z&X simultaneously when interacting with a disappearing fox. Also fixed another bug in the same scenario.
- Fixed a crash when knives spawn from an aqua-colored enemy.
- Fixed a crash when collecting candy from a green-colored enemy.
- Fixed a situation where Kris could be gigantic and the game was unplayable if you had modified your save file in a previous chapter.
- The last boss of the chapter will now get gradually easier after losing an excessive amount of times in one play session.

> We will continue to address issues as quickly as we can. We will also submit a patch to consoles as soon as possible. Thank you for your patience and for playing the game!
